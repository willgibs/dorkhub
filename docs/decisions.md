- 2026-10-13 · The Hub (shared rabbit holes) is left out of launch.
- 2026-10-13 · Trial units are reserved before the writer starts and refunded only if nothing was bought (writer failed, or the reader left before it started). Hanging up mid-write is charged, so dropped requests can't spend Dorkhub's tokens for free.

- 2026-10-15 · **Format v3 and the page cache** (PR A, almost invisible to readers):
  - `# Title :: kind`: the writer names the topic's kind and shapes the page to it; in PR B the kind sets the page's accent and its colour in the graph. The kind counts once the title line is whole, so it never flips while streaming, and "::" without spaces stays part of a title ("std::vector").
  - `===` is exactly six cards (`- [[Topic]] :: hook :: kind`), at least two leaping into another field; no `~` bridge, no `>>>` next page, no directions, no path callbacks. Links are named the way an encyclopedia titles its articles ("Mercury (planet)"), so a topic gets the same name on every page and repeats line up. Questions name their subject so they stand alone. The recap's heading is "Where to go next" (the brand rule).
  - The prompt puts the fixed instructions first and the request last. Peeks, expands, sketches and "around this" drop the path too, so they repeat as well; "around this" asks for 10 and the page hides the ones already read. `PROMPT_VERSION` is `2026-10-15-v3`.
  - Server order: a seed, then a cache hit (both free and before the trial gate, so repeats work even when the trial is over or paused, and they set no cookie), then `cachedOnly` stops with 204, then the trial and the write. `cachedOnly` is for PR B's prefetch and never writes, reserves or sets a cookie.
  - Cache keys carry the deployment (`text` in production, `text-preview`, `text-local`), so preview and mock pages never reach production.
  - Seeds are a flat index by topic, served to every reader in the default voice, keys included: they are our best, checked pages. Never for a rewrite, a connecting page or a name chosen inside another page, which may mean something else there ("Atlantis" on a page about space shuttles). The old index shape still loads. Side effect, intended: a link to a pre-written topic is free from any page.
  - Only rewriting a page in the voice it is already in is private (`fresh`); a retry, another voice or a page after adding a key may come from cache.
  - The 27 recordings were converted to v3 by script (`scripts/recorded.mjs v3`), with no model. Three still say "your path" in their prose and wait for a re-record, which needs Will's go.
